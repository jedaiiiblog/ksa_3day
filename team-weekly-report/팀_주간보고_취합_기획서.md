# 팀 주간 보고서 취합 및 기여도 산출 자동화 기획서

> 실습용 기획서입니다. 답이 없는 항목은 "확인 필요"로 남겨 두었습니다.

## 1. 반복하는 일
- 매주 금요일 오후 마감까지 5명 팀원이 프로젝트별 주간 보고 내용을 입력하면, 팀 취합 담당자가 개인별로 취합합니다.
- 월말 기준으로 그 달의 팀원별 기여도를 계산해 상위부서에 PPT로 보고합니다.
- 상위부서에 제출하는 주기가 매주인지 월말 1회인지는 확인 필요입니다.

## 2. 지금 방식
- 주간 보고서 원본이 아직 없어서, 입력 양식(항목과 작성 위치)부터 새로 정해야 합니다.
- 팀원이 파일에 입력하고 저장하면, 저장 시각이 빠른 순서대로 팀 취합 담당자가 모읍니다.
- 공휴일과 휴가 일자는 달력을 보고 확인합니다.
- 취합한 내용을 PPT로 옮기는 과정은 확인 필요입니다.

## 3. 걸리는 시간
- 한 번에 걸리는 시간은 확인 필요입니다.
- 반복 횟수는 주 1회 취합(금요일 오후 마감 후)과 월 1회 기여도 계산입니다.

## 4. 불편한 지점
- 시간이 오래 걸리거나 실수가 생기는 단계는 확인 필요입니다.
- 마감을 넘겨 늦게 저장된 파일을 어떻게 처리하는지도 확인 필요입니다.

## 5. 자동화할 부분

| 구분 | 내용 |
|---|---|
| **코드가 할 일** | 실습 폴더에서 해당 주(월)의 입력 파일 찾기, 팀원별로 파일 고르기, 저장 시각 기준으로 정렬, 마감 시각 이후 저장 파일 표시, 파일 읽기, 팀원별 프로젝트 개수 세기, 월 근무일 수 계산(공휴일·휴가 제외), 기여도 계산, 결과 PPT 저장 |
| **AI가 할 일** | 팀원별 입력 내용을 프로젝트별로 요약·분류하고, 상위부서 보고용 문장 초안 작성 |
| **사람이 확인할 일** | ① 팀원별 프로젝트 개수가 맞는지 ② 달력에서 확인한 공휴일·휴가 일자가 입력 파일에 맞게 옮겨졌는지 ③ 기여도 계산 결과 ④ 요약 문장과 최종 PPT (상위부서 제출 전, 팀 취합 담당자가 검토) |

기여도는 숫자 계산이므로 AI가 아니라 코드가 맡습니다.

## 6. 데이터 위치
- **원본 형식:** 주간 보고서 PPT(.pptx)는 아직 없습니다. 새로 만들 때의 형식은 확인 필요입니다.
- **실습용 형식:** UTF-8 텍스트 파일(.md 또는 .txt)입니다. 바탕화면의 "실습" 폴더에 팀원별로 1개씩 두는 방식을 제안하며, 확인 필요입니다. 원본 형식은 확인 없이 바꾸지 않습니다.
- **입력 양식 (제안, 확인 필요):** 팀원 이름, 프로젝트명(여러 개), 프로젝트별 주간 내용을 적는 텍스트 양식입니다.
- **공휴일·휴가:** 원본은 달력입니다. 어떤 달력(회사 공용 달력, 개인 달력 등)인지는 확인 필요입니다. 실습용으로는 달력을 보고 공휴일과 팀원별 휴가 일자를 텍스트 파일에 옮겨 적는 방식을 제안하며, 확인 필요입니다.
- **파일 저장 시각 사용 시 유의점:** 파일을 복사하거나 옮기면 저장 시각이 바뀔 수 있어서, 팀원이 실습 폴더에 직접 저장하는 방식이어야 순서가 맞습니다. 확인 필요입니다.

## 7. 성공 기준
- **결과 형식:** 상위부서 보고용 PPT(.pptx)입니다.
- **저장 위치:** 바탕화면의 "실습" 폴더입니다.
- **슬라이드 구성 (제안, 확인 필요):** 팀 전체 요약 1장에 팀원별 1장씩(프로젝트 요약과 기여도)을 더한 구성입니다. 팀원 순서는 저장 시각 순서를 따르는 안입니다.
- **빠지면 안 되는 내용:** 팀원별 프로젝트 목록과 개수, 프로젝트별 요약, 월 기준 기여도(시간, 개인 기준 %, 팀 대비 비중 %)입니다. 상위부서가 요구하는 다른 항목은 확인 필요입니다.
- **기여도 계산 기준:**
  1. 근무시간은 1인당 하루 8시간, 월~금 주 40시간입니다.
  2. **개인 월 기준 시간** = (해당 월의 월~금 일수 − 공휴일 − 해당 팀원의 휴가일) × 8시간입니다. 반차 등 하루 미만 휴가를 다룰지는 확인 필요입니다.
  3. **프로젝트별 시간** = 개인 월 기준 시간 ÷ 그 팀원의 프로젝트 개수입니다.
  4. **팀 대비 비중(%)** = 개인 월 기준 시간 ÷ 팀 5명의 월 기준 시간 합계입니다. 프로젝트별 팀 대비 비중은 프로젝트별 시간 ÷ 팀 합계로 계산합니다.
  5. 휴가가 많은 팀원은 개인 월 기준 시간이 줄어 팀 대비 비중도 낮아집니다.
- **계산 예시 (설명용 가상값):** 팀원 A의 근무일이 20일이면 160시간이고, 프로젝트가 4개면 프로젝트당 40시간입니다. 팀 합계가 760시간이면 A의 팀 대비 비중은 160 ÷ 760 ≈ 21.1%입니다.

## 8. 이번에 안 할 것 (제안, 확인 필요)
- 팀원이 실제로 투입한 시간을 읽어 반영하는 기능 (이번에는 프로젝트 개수 균등 분배만 적용)
- 달력에서 공휴일·휴가를 자동으로 가져오는 기능 (실습은 텍스트로 옮겨 적은 내용 기준)
- 기존 PPT에서 텍스트를 자동으로 뽑는 기능 (원본이 아직 없고, 첫 실습은 텍스트 파일 기준)
- 팀원 입력용 화면이나 폼 제작
- 상위부서로 자동 발송, 마감 알림
- 팀원 간 순위 매기기, 인사평가 연결
- 월 외의 다른 기간(분기 등) 계산
- 이미지·차트가 들어간 슬라이드 처리

## 9. 누가 쓰나
- **사용자:** 팀 취합 담당자입니다.
- **결과를 받는 쪽:** 상위부서입니다.
- **사용 상황:** 매주 금요일 오후 마감 후 입력 파일을 저장 시각 순으로 취합하고, 월말에는 그 달의 기여도를 계산해 PPT로 만든 뒤 검토해서 상위부서에 보고합니다.

## 남은 확인 사항
1. 취합 시 가장 오래 걸리거나 실수가 잦은 단계, 한 번에 걸리는 시간 (3, 4번)
2. 금요일 마감 시각과 마감 후 저장된 파일의 처리 방법 (1, 4번)
3. 상위부서 제출 주기(매주 또는 월말 1회) (1번)
